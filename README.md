📋 Interactive List

Um aplicativo de lista interativa atualizado em tempo real, permitindo compartilhamento com qualquer pessoa. A lista compartilhada pode ser acessada tanto no aplicativo mobile quanto em um navegador no PC.

🚀 Tecnologias Utilizadas

React Native - Para a interface e funcionalidade do app mobile.

Firebase - Para autenticação, banco de dados em tempo real e armazenamento.

TypeScript - Para um código mais seguro e tipado.

Next.js - Para a versão web do aplicativo.


📲 Como Rodar o Projeto

Requisitos

Node.js instalado

Expo CLI instalado globalmente (npm install -g expo-cli)

Conta no Firebase e um projeto configurado

Passos

Clone o repositório,

Acesse a pasta do projeto,

Instale as dependências:

npm install


expo start

🌎 Versão Web

Para acessar a lista no PC, utilize a versão web feita com Next.js. Basta abrir o link correspondente após o compartilhamento da lista.

🛠 Funcionalidades

Criar listas interativas

Atualização em tempo real

Compartilhamento de listas

Acesso via aplicativo e navegador

Interface intuitiva e responsiva
